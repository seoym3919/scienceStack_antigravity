# Golden Dataset & Industry Standard Benchmark

Never validate scientific software on ad-hoc, toy inputs.

Scientific computing requires validation against **industry-standard test problems** (canonical benchmark geometries, parameters, and initial conditions) and **golden datasets** (authoritative reference data generated by analytical solutions, NIST standards, or verified high-precision reference solvers).

---

## 1. Catalog of Canonical Industry-Standard Benchmarks

Match the problem domain to its classical reference problem:

| Domain | Canonical Benchmark Problem | Key Observable / Golden Metric |
| :--- | :--- | :--- |
| **Compressible Fluid Dynamics** | Sod Shock Tube (1D Euler) | Exact Riemann shock, contact, rarefaction profiles |
| **Incompressible Navier-Stokes** | Lid-Driven Cavity ($Re=100, 1000$) | Centerline velocity profiles ($u(y), v(x)$), vortex centers (Ghia et al. 1982) |
| **Vorticity / Turbulence** | Taylor-Green Vortex (3D) | Kinetic energy dissipation rate $-dK/dt$ over time |
| **Solid Mechanics / FEM** | Cook's Membrane Problem | Tip vertical displacement, stress concentration at corner |
| **Elasticity / Structural** | Timoshenko Beam with End Load | Analytical deflection vs. shear deformation parameter |
| **Molecular Dynamics** | Liquid Argon (Lennard-Jones, NVE) | Radial distribution function $g(r)$, diffusion coefficient, energy drift |
| **Stiff Reaction Kinetics** | Robertson Chemical Kinetics ($10^4$ ratio) | Concentration profiles $[A], [B], [C]$ over $t \in [0, 10^5]$ |
| **Astrodynamics / N-Body** | Circular Restricted Three-Body Problem | Jacobi integral conservation, Lagrange point stability |
| **Quantum Chemistry / Structure** | 1D Quantum Harmonic Oscillator & $H_2$ Morse | Ground/excited state eigenvalues $E_n = \hbar \omega (n + 1/2)$, dissociation curve |
| **Numerical Linear Algebra** | Hilbert, Wilkinson, Kahan matrices | Condition number $\kappa(A)$, residual $\|Ax - b\| / \|b\|$ |

## 2. Protocols for Establishing Golden Datasets

### Protocol A: Closed-Form Analytical & High-Precision Evaluation
- For problems with exact solutions (e.g. Sod shock tube, 1D heat diffusion series, wave d'Alembert, Kepler orbits):
  - Evaluate the analytical solution using arbitrary-precision arithmetic (`mpmath` or `sympy` with 50+ digits) to eliminate floating-point reference error.
  - Sample onto target evaluation grids.

### Protocol B: Authoritative Industry Databases & Literature Standards
- Ingest certified reference data from standard repositories:
  - **NIST Standard Reference Data**: Fundamental physical constants, spectral line databases, thermodynamics datasets.
  - **NASA CEA / SP-273**: Chemical equilibrium and rocket performance tables.
  - **Ghia et al. (1982)**: Standard velocity tables for 2D lid-driven cavity.
  - **SuiteSparse Matrix Collection / NETLIB**: Canonical sparse linear systems.

### Protocol C: Method of Manufactured Solutions (MMS)
- When no closed-form solution exists for nonlinear coupled PDEs:
  - Choose a manufactured smooth field: $u_{\text{mms}}(x, y, t) = \sin(\pi x) \cos(\pi y) e^{-\alpha t}$.
  - Symbolically compute source terms $S = \mathcal{D}(u_{\text{mms}})$ with `sympy`.
  - The manufactured field $u_{\text{mms}}$ serves as the exact golden target.

## 3. Storing and Versioning Golden Datasets

Store golden reference datasets in a dedicated, reproducible project directory:

```text
tests/golden/
├── <benchmark-slug>/
│   ├── golden_reference.npz (or .h5 / .csv / .parquet)
│   ├── metadata.json
│   └── generate_golden.py
```

## 4. Verification & Validation (V&V) Harness

Every golden verification test must compute explicit mathematical error norms against the golden reference:

1. **Relative $L_2$ Error Norm**:
   $$\epsilon_{L_2} = \frac{\| \mathbf{y}_{\text{code}} - \mathbf{y}_{\text{golden}} \|_2}{\| \mathbf{y}_{\text{golden}} \|_2} = \frac{\sqrt{\sum_i (y_i - y_{\text{gold}, i})^2}}{\sqrt{\sum_i y_{\text{gold}, i}^2}}$$

2. **Maximum Pointwise Error ($L_\infty$)**:
   $$\epsilon_{L_\infty} = \max_i | y_i - y_{\text{gold}, i} |$$

3. **Assert Explicit Tolerance Gates**:
   ```python
   def test_sod_shock_tube_against_golden():
       golden = np.load("tests/golden/sod_shock_tube/golden_reference.npz")
       result = run_simulation(sod_config)
       
       rel_l2 = np.linalg.norm(result.density - golden["density"]) / np.linalg.norm(golden["density"])
       max_err = np.max(np.abs(result.density - golden["density"]))
       
       # Assert against predetermined discretization tolerance
       assert rel_l2 < 1.5e-3, f"Relative L2 error {rel_l2} exceeded threshold"
       assert max_err < 0.05, f"Maximum pointwise error {max_err} exceeded threshold"
   ```

4. **Regression Lock**:
   Never loosen the golden tolerance threshold to accommodate a modified algorithm. A rise in error against a golden dataset is an immediate regression signal.
