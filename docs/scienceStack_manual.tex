\section*{Executive Summary}
\addcontentsline{toc}{chapter}{Executive Summary}

In traditional software engineering, artificial intelligence coding assistants often generate superficial code that satisfies local syntax tests but fails under boundary conditions. In \textbf{computational science and engineering}, the cost of generated ``slop'' is catastrophic. A flipped negative sign in a Laplacian diffusion operator turns a dissipative physical process into an exponentially explosive numerical instability. A subtle catastrophic cancellation in floating-point subtraction silently destroys the condition number of a linear solve. An unverified normalization constant renders quantum wavefunctions non-unitary.

\textbf{scienceStack} is an Antigravity-native agentic framework engineered specifically to eliminate ungrounded code in scientific and mathematical computing. Originating from the battle-tested \texttt{pstack} architecture created by Lauren Tan at Cursor, \texttt{scienceStack} completely re-architects the agent pairing paradigm for Google Antigravity:
\begin{enumerate}[itemsep=2pt]
    \item \textbf{Theoretical Provenance}: Every formula implemented by an agent must be explicitly derived in LaTeX docstrings, cite canonical literature equations, and define coordinate metrics and sign conventions.
    \item \textbf{Dimensional Discipline}: Every equation is verified for physical dimension matching ($[\mathrm{LHS}] = [\mathrm{RHS}]$), and transcendental arguments ($\exp, \ln, \sin$) are enforced to be dimensionless.
    \item \textbf{Conservation Law Guarantees}: Numerical schemes are required to track and conserve physical invariants (energy, mass, momentum, probability norm) within specified tolerance thresholds.
    \item \textbf{Numerical Stability First}: The framework strictly bans naive mathematical implementations (e.g., explicit matrix inversion $\mathbf{A}^{-1}\mathbf{b}$, unscaled floating-point differences) in favor of conditioned algorithms (\texttt{solve(A, b)}, \texttt{logsumexp}, \texttt{expm1}).
    \item \textbf{Analytical Limits \& Golden Datasets}: Every scientific kernel must be validated against closed-form exact solutions, the Method of Manufactured Solutions (MMS), or canonical industry benchmark datasets (e.g., Sod shock tube, Taylor-Green vortex, Robertson stiff ODEs).
    \item \textbf{Physics-Modular Architecture}: Physical laws, equations of state, forces, and rate equations must be isolated into dedicated, driver-agnostic modules (\texttt{physics/}) so other simulation codes and external solvers can invoke them directly without coupling to numerical time steppers or spatial grids.
\end{enumerate}

With 35 top-level skills, 30 bundled scientific and software engineering principles, three specialized subagent personas (\texttt{science-master}, \texttt{theory-reviewer}, and \texttt{comment-master}), and native Antigravity asynchronous orchestration, \texttt{scienceStack} enables fearless parallel development while upholding the mathematical rigor demanded by modern science.

\chapter{System Overview and Core Philosophy}

\section{The Crisis of Slop in Scientific Computing}

Modern Large Language Models (LLMs) excel at generating idiomatic code snippets, web components, and routine test scripts. However, when applied to computational physics, numerical linear algebra, biomechanics, or quantum chemistry, unassisted LLMs exhibit severe failure modes:
\begin{itemize}[itemsep=4pt]
    \item \textbf{Hallucinated Equations}: Formulating plausible-looking discrete approximations that lack theoretical backing or violate fundamental symmetries.
    \item \textbf{Catastrophic Floating-Point Cancellation}: Evaluating expressions like $f(x) = \sqrt{x+1} - \sqrt{x}$ or $(1 - \cos x)$ for small $x$ without using Taylor series or conditioned algebraic identities, leading to severe loss of significance.
    \item \textbf{Inversion of Ill-Conditioned Matrices}: Emitting $\mathbf{x} = \mathbf{A}^{-1}\mathbf{b}$ via \texttt{numpy.linalg.inv(A) @ b} instead of direct LU/Cholesky/QR solvers, squaring the matrix condition number $\kappa(\mathbf{A})$.
    \item \textbf{Violation of Noetherian Invariants}: Implementing time-integration schemes (such as standard forward Euler) for conservative Hamiltonian systems, causing artificial energy blowup over time.
    \item \textbf{Narrative Noise in Codebases}: Polluting clean mathematical code with conversational comments, redundant stubs, and defensive workarounds that obscure algorithmic clarity.
\end{itemize}

\section{The scienceStack Philosophy}

\texttt{scienceStack} operates on a single immutable maxim:
\begin{center}
    \textbf{\Large ``If you want to go fast, go deep first.''}
\end{center}
Throughput without theoretical accuracy is counterproductive. Generating ten thousand lines of unverified simulation code produces negative value if the underlying discretization violates conservation laws. 

\subsection{Fearless Parallelism}
In traditional development, delegating work to multiple concurrent background agents leads to merge conflicts, architectural drift, and silent bugs. \texttt{scienceStack} makes parallelism safe by establishing strict entry contracts, formal verification suites, and autonomous review panels:
\begin{itemize}
    \item \textbf{Isolated Workspaces}: Concurrent subagents execute inside isolated Git branches or worktrees (\texttt{Workspace: "branch"}).
    \item \textbf{Theoretical Gatekeepers}: No scientific kernel is merged into the primary branch until audited by the independent \texttt{theory-reviewer} subagent.
    \item \textbf{Objective Golden Benchmarks}: Work is considered complete only when empirical convergence rates $O(h^p)$ or relative $L_2$ error thresholds against reference datasets are demonstrated.
\end{itemize}

\section{theory-reviewer: The Mathematical Auditor}

\subsection{The 6-Point Theoretical Audit Checklist}
When auditing a diff, \texttt{theory-reviewer} executes a rigorous verification pass:
\begin{enumerate}
    \item \textbf{Continuous Equation Provenance}: Does every mathematical function specify its continuous formulation in LaTeX in docstrings, citing the textbook or paper equation number?
    \item \textbf{Coordinate System \& Sign Conventions}: Are spatial metrics ($g_{ij}$), coordinate systems (Cartesian, cylindrical, spherical), and sign conventions documented? For instance, in diffusion:
    \begin{equation}
        \frac{\partial u}{\partial t} = +\alpha \nabla^2 u \quad (\text{stable diffusion, } \alpha > 0)
    \end{equation}
    A negative sign would represent reverse-time anti-diffusion, causing ill-posed exponential growth.
    \item \textbf{Dimensional Homogeneity}: Do physical units match on both sides of every assignment? Are arguments to transcendental functions strictly dimensionless:
    \begin{equation}
        \exp\left(-\frac{E_a}{k_B T}\right) \quad \text{where } \left[\frac{E_a}{k_B T}\right] = 1
    \end{equation}
    \item \textbf{Tensor and Index Order}: Are multi-dimensional arrays adhering to explicit indexing standards (row-major vs column-major, Einstein summation)?
    \item \textbf{Normalization Constants}: Are integral normalizations preserved? E.g., for Fourier transforms:
    \begin{equation}
        \hat{f}(\xi) = \int_{-\infty}^{\infty} f(x) e^{-2\pi i x \xi} dx \implies f(x) = \int_{-\infty}^{\infty} \hat{f}(\xi) e^{2\pi i x \xi} d\xi
    \end{equation}
    Or probability densities: $\int_{\Omega} |\psi(\mathbf{x}, t)|^2 d\mathbf{x} \equiv 1$.
    \item \textbf{Physical Invariant Conservation}: Does the discrete formulation preserve Noetherian invariants (mass, energy, momentum, symplecticity) over simulation time?
\end{enumerate}

\chapter{The Six Core Scientific Principles}

\section{Principle 1: Equation Provenance and Formal Documentation}
\textbf{Principle File}: \texttt{skills/science-mode/principles/equation-provenance.md}

Every mathematical function or kernel in a scientific codebase must declare its provenance. Code without equation provenance is untestable against theory.

\begin{principlebox}{Equation Provenance}
Every scientific implementation must:
\begin{enumerate}
    \item State the continuous governing equation in LaTeX within the function docstring.
    \item Cite the source paper or textbook with explicit chapter, page, or equation number.
    \item Document coordinate system, metric tensor, and sign conventions.
\end{enumerate}
\end{principlebox}

\subsection{Code Comparison: Bad vs. Compliant}
\begin{lstlisting}[language=Python, caption={Non-compliant ungrounded function}]
# Bad: No provenance, ambiguous variables, undocumented formula
def calc_stress(e, nu, E):
    return E / ((1 + nu) * (1 - 2*nu)) * ((1 - nu) * e[0] + nu * e[1])
\end{lstlisting}

\begin{lstlisting}[language=Python, caption={Compliant function with Equation Provenance}]
def plane_strain_normal_stress(
    strain_xx: float, 
    strain_yy: float, 
    youngs_modulus: float, 
    poissons_ratio: float
) -> float:
    r"""
    Compute normal stress \sigma_{xx} under isotropic linear elastic plane strain.

    Governing Continuous Equation:
    \begin{equation}
        \sigma_{xx} = \frac{E}{(1+\nu)(1-2\nu)} \left[ (1-\nu)\varepsilon_{xx} + \nu\varepsilon_{yy} \right]
    \end{equation}

    Reference:
        Timoshenko, S. P., & Goodier, J. N. (1970). "Theory of Elasticity", 
        3rd ed., McGraw-Hill, Chapter 2, Eq. (11.3), p. 34.

    Assumptions & Conventions:
        - Coordinate System: Cartesian (x, y, z)
        - Condition: Plane strain (\varepsilon_{zz} = \gamma_{xz} = \gamma_{yz} = 0)
        - Sign Convention: Tensile stress is positive (> 0).
    """
    E, nu = youngs_modulus, poissons_ratio
    coeff = E / ((1.0 + nu) * (1.0 - 2.0 * nu))
    return coeff * ((1.0 - nu) * strain_xx + nu * strain_yy)
\end{lstlisting}

\section{Principle 2: Dimensional Discipline \& Scaling}
\textbf{Principle File}: \texttt{skills/science-mode/principles/dimensional-discipline.md}

Physical quantities possess dimensions in fundamental SI units ($[M], [L], [T], [\Theta], [I]$). Dimensional mismatch is proof of a mathematical bug.

\begin{principlebox}{Dimensional Discipline}
\begin{enumerate}
    \item Verify dimensional homogeneity: $[\mathrm{LHS}] = [\mathrm{RHS}]$ for every physical relation.
    \item Nondimensionalize equations using characteristic scales prior to numerical integration:
    \begin{equation}
        x^* = \frac{x}{L_0}, \quad t^* = \frac{t U_0}{L_0}, \quad p^* = \frac{p}{\rho_0 U_0^2}
    \end{equation}
    \item Verify that arguments to transcendental functions ($\exp, \ln, \sin, \cos$) are strictly dimensionless ($[f(\arg)] = 1 \implies [\arg] = 1$).
\end{enumerate}
\end{principlebox}

\section{Principle 3: Preservation of Physical Conservation Laws}
\textbf{Principle File}: \texttt{skills/science-mode/principles/preserve-conservation-laws.md}

According to Noether's theorem, every continuous physical symmetry corresponds to a conserved invariant:
\begin{itemize}
    \item Time translation invariance $\implies$ Energy conservation ($\frac{dE}{dt} = 0$).
    \item Spatial translation invariance $\implies$ Linear momentum conservation ($\frac{d\mathbf{p}}{dt} = \mathbf{0}$).
    \item Spatial rotational invariance $\implies$ Angular momentum conservation ($\frac{d\mathbf{L}}{dt} = \mathbf{0}$).
    \item Phase invariance (gauge symmetry) $\implies$ Charge / probability norm conservation ($\int |\psi|^2 dx = 1$).
\end{itemize}

Standard dissipative discrete schemes (such as implicit backward Euler) artificially dissipate energy, while explicit schemes often artificially inject energy. \texttt{scienceStack} mandates \textbf{invariant tracking}:
\begin{equation}
    \delta(t) = \frac{|I(t) - I(0)|}{|I(0)|} \le \tau_{\mathrm{drift}}
\end{equation}

\section{Principle 4: Numerical Stability First}
\textbf{Principle File}: \texttt{skills/science-mode/principles/numerical-stability-first.md}

Numerical algorithms must remain stable in floating-point arithmetic ($\text{IEEE-754}$). Premature vectorization must never compromise numerical conditioning.

\begin{warningbox}{Catastrophic Cancellation}
Subtracting two nearly equal floating-point numbers $a \approx b$ causes severe cancellation, wiping out significant bits:
\begin{equation}
    \text{Error}_{\text{rel}} \approx \frac{\epsilon_{\text{mach}}}{|a - b|}
\end{equation}
Use conditioned mathematical identities or special functions:
\begin{itemize}
    \item Replace $1 - \cos x$ with $2 \sin^2(x/2)$ for $|x| \ll 1$.
    \item Replace $\ln(1 + x)$ with \texttt{math.log1p(x)}.
    \item Replace $e^x - 1$ with \texttt{math.expm1(x)}.
    \item Replace $\ln\sum e^{x_i}$ with \texttt{scipy.special.logsumexp(x)}.
\end{itemize}
\end{warningbox}

\begin{warningbox}{Strict Matrix Inversion Prohibition}
Never compute $\mathbf{x} = \mathbf{A}^{-1}\mathbf{b}$ via \texttt{numpy.linalg.inv(A) @ b}. Matrix inversion introduces an operation count of $2n^3$ flops and squares the numerical condition number:
\begin{equation}
    \kappa(\mathbf{A}) = \|\mathbf{A}\| \|\mathbf{A}^{-1}\|
\end{equation}
Always compute linear solves via direct factorization or Krylov iterative methods:
\begin{lstlisting}[language=Python]
# FORBIDDEN:
x = np.linalg.inv(A) @ b

# MANDATED:
x = np.linalg.solve(A, b)
# Or for symmetric positive definite matrices:
# L = scipy.linalg.cho_factor(A); x = scipy.linalg.cho_solve(L, b)
\end{lstlisting}
\end{warningbox}

\textbf{Principle File}: \texttt{skills/science-mode/principles/verify-analytical-limits.md}

Unit tests asserting that code ``runs without throwing an exception'' are insufficient for scientific software. Verification requires rigorous mathematical convergence:
\begin{enumerate}

    \item \textbf{Method of Manufactured Solutions (MMS)}: For nonlinear or coupled PDEs without closed-form solutions, manufacture an analytical solution $u_{\text{exact}}(\mathbf{x}, t)$, substitute into the PDE to derive an analytical source term $f_{\text{mms}}$, and verify that the discrete solver converges to $u_{\text{exact}}$ at the theoretical asymptotic rate $O(h^p)$:

\section{Principle 6: Physics-Modular Architecture \& Decoupled Operators}
\textbf{Principle File}: \texttt{skills/science-mode/principles/physics-modular-architecture.md}

Scientific simulation software frequently degrades into monolithic codebases where physics governing laws (e.g., gravitational accelerations, nuclear reaction networks, equations of state, radiative transfer opacity, stress-strain tensors) are tightly entangled with numerical time steppers (Runge-Kutta, Leapfrog), spatial mesh topologies, and file I/O operations.

When physical models are monolithic, external research codes, alternate integrators, and higher-order solvers cannot invoke the physics routines independently. \texttt{scienceStack} mandates a strict \textbf{Physics-Modular Architecture}:

\begin{principlebox}{Physics-Modular Architecture}
\begin{enumerate}
    \item \textbf{Decouple Physics from Numerics}:
    Isolate pure physical laws into dedicated, stateless modules (\texttt{physics/}). Physics operators must accept pure state vectors $\mathbf{y}$ and physical parameters $\mathbf{p}$, computing state derivatives $\frac{d\mathbf{y}}{dt}$, accelerations $\mathbf{a}_i$, or fluxes $\mathbf{F}(\mathbf{u})$ without time-stepping logic or grid allocations:
    \begin{equation}
        \mathbf{a}_i = \mathcal{F}_{\text{phys}}(\{\mathbf{q}_j\}, \{m_j\}, G, \epsilon)
    \end{equation}
    \item \textbf{Generalized Numerical Steppers}:
    Numerical integrators (e.g., symplectic Leapfrog, Radau, BDF) must be physics-agnostic, accepting an arbitrary callable physics operator:
    \begin{equation}
        \mathbf{y}^{n+1} = \mathcal{I}_{\text{stepper}}(\mathbf{y}^n, \Delta t, \mathcal{F}_{\text{phys}})
    \end{equation}
    \item \textbf{Driver-Agnostic Composability}:
    Ensure external solvers or other analysis codes can directly import and execute the physics module without instantiating simulation drivers.
\end{enumerate}
\end{principlebox}

\section{Overview of the Astronomy Suite}
Astronomy, astrophysics, and celestial mechanics impose stringent mathematical demands on computational algorithms. Planetary and stellar systems are Hamiltonian and non-dissipative; standard explicit integrators introduce artificial secular energy drift that destroys orbital stability over astronomical integration intervals. Coordinate transformations require direction cosine matrices in $\mathrm{SO}(3)$ that must preserve unit norm and orthogonality to machine precision. Stellar structure equations exhibit coordinate singularities at the stellar core ($\xi = 0$) that require analytical series expansions before numerical stepping.

\texttt{scienceStack} provides four bundled, zero-network reference solvers in \texttt{benchmarks/astronomy/}:
\begin{enumerate}
    \item \textbf{\texttt{kepler\_solver.py}}: Universal Kepler equation solver for elliptic and hyperbolic motion with cubic Halley iteration and Cartesian orbit propagation.
    \item \textbf{\texttt{symplectic\_nbody.py}}: Symplectic Leapfrog and Yoshida integrators for gravitationally interacting $N$-body systems with exact energy and angular momentum tracking.
    \item \textbf{\texttt{lane\_emden\_solver.py}}: Stellar structure polytropic solver with near-center series expansion removing the $2/\xi$ coordinate singularity.
    \item \textbf{\texttt{coordinate\_transforms.py}}: Direction cosine transformations between Equatorial (J2000 ICRS), Ecliptic, and Galactic coordinate systems.
\end{enumerate}

\section{Kepler Orbit Propagation and Vis-Viva Invariants}
\subsection{Mathematical Formulation}
For two-body gravitational motion under central potential $V(r) = -\mu/r$, Kepler's equation for elliptic orbits ($0 \le e < 1$) relates mean anomaly $M(t) = n(t - t_0)$ to eccentric anomaly $E$:
\begin{equation}
    M = E - e \sin E
\end{equation}
The true anomaly $\nu$ is obtained without quadrant ambiguity or cancellation via:
\begin{equation}
    \tan\frac{\nu}{2} = \sqrt{\frac{1+e}{1-e}} \tan\frac{E}{2}
\end{equation}
The orbital radius and perifocal state vector are:
\begin{equation}
    r = a(1 - e \cos E), \quad \mathbf{r}_{\text{orb}} = \begin{bmatrix} r \cos\nu \\ r \sin\nu \\ 0 \end{bmatrix}, \quad \mathbf{v}_{\text{orb}} = \frac{\mu}{h} \begin{bmatrix} -\sin\nu \\ e + \cos\nu \\ 0 \end{bmatrix}
\end{equation}
where $h = \sqrt{\mu a (1 - e^2)}$ is the specific angular momentum.

\subsection{Cubic Halley Solver}
For high eccentricities ($e \to 1$), standard Newton-Raphson oscillates or converges slowly. \texttt{scienceStack} implements third-order Halley acceleration:
\begin{equation}
    \Delta_1 = -\frac{f(E)}{f'(E)}, \quad \Delta_{\text{Halley}} = -\frac{f(E)}{f'(E) + \frac{1}{2} \Delta_1 f''(E)}
\end{equation}
where $f(E) = E - e \sin E - M$, $f'(E) = 1 - e \cos E$, and $f''(E) = e \sin E$. This method achieves machine precision ($|E_{k+1} - E_k| < 10^{-14}$) in 3 iterations.

\subsection{Invariant Verification}
Every propagated state $(\mathbf{r}, \mathbf{v})$ must satisfy the vis-viva equation:
\begin{equation}
    \mathcal{E} = \frac{v^2}{2} - \frac{\mu}{r} = -\frac{\mu}{2a}
\end{equation}
and specific angular momentum conservation $\mathbf{h} = \mathbf{r} \times \mathbf{v}$. The reference solver asserts that both invariants deviate by less than $10^{-14}$ in double precision.

\section{Symplectic Gravitational N-Body Dynamics}
\subsection{The Hamiltonian and Symplectic Structure}
An $N$-body gravitational system is governed by the Hamiltonian:
\begin{equation}
    H(\mathbf{q}, \mathbf{p}) = \sum_{i=1}^N \frac{\mathbf{p}_i^2}{2 m_i} - \sum_{1 \le i < j \le N} \frac{G m_i m_j}{\|\mathbf{q}_i - \mathbf{q}_j\|}
\end{equation}
Standard integrators (such as Runge-Kutta 4th order) are non-symplectic: they fail to preserve the differential 2-form $\omega = \sum_i d\mathbf{q}_i \wedge d\mathbf{p}_i$. Over thousands of orbital periods, non-symplectic integrators introduce artificial dissipation or excitation, causing orbits to decay or blow up.

\subsection{Drift-Kick-Drift Leapfrog}
\texttt{scienceStack} implements the symplectic 2nd-order Drift-Kick-Drift (DKD) scheme:
\begin{align}
    \mathbf{q}_i^{n+1/2} &= \mathbf{q}_i^n + \frac{\Delta t}{2} \mathbf{v}_i^n \\
    \mathbf{v}_i^{n+1} &= \mathbf{v}_i^n + \Delta t \, \mathbf{a}_i(\mathbf{q}^{n+1/2}) \\
    \mathbf{q}_i^{n+1} &= \mathbf{q}_i^{n+1/2} + \frac{\Delta t}{2} \mathbf{v}_i^{n+1}
\end{align}
where gravitational accelerations $\mathbf{a}_i = -G \sum_{j \neq i} m_j \frac{\mathbf{q}_i - \mathbf{q}_j}{\|\mathbf{q}_i - \mathbf{q}_j\|^3}$ satisfy Newton's third law ($\mathbf{F}_{ij} = -\mathbf{F}_{ji}$).
Because DKD is symplectic, the numerical trajectory exactly traces a nearby ``shadow Hamiltonian'' $\tilde{H} = H + O(\Delta t^2)$, ensuring that total energy $E(t)$ oscillates boundedly with zero secular growth over $10^5$ steps.

\section{Stellar Structure: Lane-Emden Polytropes}
\subsection{Governing Equation and Singularity Removal}
Hydrostatic equilibrium and a polytropic equation of state ($P = K \rho^{1 + 1/n}$) yield the dimensionless Lane-Emden equation:
\begin{equation}
    \frac{1}{\xi^2} \frac{d}{d\xi}\left( \xi^2 \frac{d\theta}{d\xi} \right) + \theta^n = 0 \iff \frac{d^2\theta}{d\xi^2} + \frac{2}{\xi}\frac{d\theta}{d\xi} + \theta^n = 0
\end{equation}
with central boundary conditions $\theta(0) = 1$ and $\theta'(0) = 0$.
At $\xi = 0$, the geometry term $(2/\xi)\theta'$ creates a coordinate singularity. \texttt{scienceStack} removes this singularity by starting integration at $\xi_0 = 10^{-4}$ using the analytic series expansion:
\begin{equation}
    \theta(\xi) \approx 1 - \frac{\xi^2}{6} + \frac{n \xi^4}{120} - \frac{n(8n - 5)\xi^6}{15120} + O(\xi^8)
\end{equation}
\subsection{Analytical and Tabulated Benchmarks}
The numerical solver integrates radially outward until $\theta(\xi_1) = 0$, determining the stellar radius $\xi_1$ and mass factor $\omega_n = -\xi_1^2 \theta'(\xi_1)$:
\begin{itemize}
    \item $n = 0$ (Constant density): $\xi_1 = \sqrt{6} \approx 2.449490$, $\omega_0 = 2\sqrt{6} \approx 4.898979$.
    \item $n = 1$ (Linear polytrope): $\xi_1 = \pi \approx 3.141593$, $\omega_1 = \pi \approx 3.141593$.
    \item $n = 1.5$ (Convective stars / Non-relativistic white dwarfs): $\xi_1 \approx 3.65375$, $\omega_{1.5} \approx 2.71406$.
    \item $n = 3.0$ (Radiation-dominated stars / Relativistic Chandrasekhar limit): $\xi_1 \approx 6.89685$, $\omega_3 \approx 2.01824$.
\end{itemize}
